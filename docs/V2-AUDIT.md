# CIVIQ AI V2 audit

## Baseline

Existing repository: Advaith-Ganesh/CIVIQ, checkpoint c785e88. Next.js 16 App Router, React 19, strict TypeScript, Tailwind 4, Radix/CVA button, Prisma 6/SQLite, Leaflet, Recharts, Vitest and Playwright. The working tree was clean before baseline execution; next-env.d.ts is generated by Next.js.

Baseline verified on 17 October 2026: strict typecheck, 26 unit/integration tests and production build pass. No lint script existed. Previous GitHub Actions verified 4 browser tests; local standalone Chromium is restricted by macOS sandboxing.

## Working features

Persistent anonymous photo reports, coordinates, text classification, geographic/keyword duplicate review, unique references, council queue, assignments/dates, legal status transitions, public tracking, private notes, repair evidence, human closure and reopening. Repeatable fictional seed and safe reset. Production disables local demo auth bypass and requires a staff token. Image decoding, metadata stripping, file/pixel limits and same-host write checks exist.

## Gaps

No vision inference or semantic embeddings. OpenAI adapter deliberately unavailable, not simulated live output. Model evaluation and provenance ingestion absent. Dashboard has no contextual inspector, hotspot analysis or service routing display. Data source metadata is minimal. Six-step report flow adds avoidable friction. Green branding conflicts with V2 requirements. Prototype staff-token access is not production council SSO.

## Preservation and implementation

Git checkpoint branch v1-before-v2 preserves the source. SQLite online backup, table counts and uploaded files copied to the task work/v2-checkpoint directory; backups stay outside Git. Add columns/tables/indexes using a new migration; preserve all existing IDs and records. No reset of user data.

Increment 1: navy/slate/blue design, five-stage accessible upload wizard, command console inspector and sidebar collapse.
Increment 2: loopback FastAPI inference using official Apache-2.0 SigLIP and MiniLM weights; raw similarities, abstention, explicit errors/manual fallback, cached single-instance models.
Increment 3: source classifications and provenance, validated manifest/CSV/JSON imports, licensed image evaluation kept out of issue geography, hotspots/search/service routing/accessibility and model/data panels.
Increment 4: targeted tests, real/failing inference, preservation checks, fresh migrations, build, lint, browser workflow and screenshots; documentation and existing GitHub repository update.

# Three-minute CIVIQ AI V2 demonstration

Before presenting: run the web and Python services, download weights and evaluation photos, register metadata, and load cached models in AI Lab. Run one sample so the header can truthfully show LIVE MODEL. Keep a JPEG of a genuine local problem for reporting; do not use an international evaluation image as a Southampton report. Demo data remains explicitly fictional.

**0:00–0:25 · Purpose and evidence**
Open the landing page. Explain the resident-to-repair workflow and the independent prototype status. Show Southampton's attributed 47.1 fly-tipping incidents per 1,000 residents for 2024/25, last-known update 29 June 2026. Explain that this aggregate is separate from the fictional map issues.

**0:25–1:05 · Resident journey**
Open `/report`: upload or drop the photograph, pinpoint its real local location, describe the problem and optionally mark access obstruction. Review actual local image candidates and raw similarities, correct the category if needed, inspect nearby semantic/geographic candidates and explicitly choose association or a separate problem. Submit and show the persistent tracking reference. If inference is offline, show the clear unavailable state and manual category selection; reporting still works.

**1:05–1:45 · Coordinated operations**
Open `/dashboard`. Collapse/expand the sidebar, select a queue item or marker and inspect its photo, provenance, score and recommended configured team. Explain that associated anonymous reports are not independently verified people. Assign a team; open full details and show priority factors, lifecycle and evidence. For `/dashboard/issues/demo-3`, explain why A101 and A102 are distinct lamps and reject the intentional incorrect fixture match.

**1:45–2:15 · Repair and operational intelligence**
Show a repaired issue such as `/dashboard/issues/demo-12`: before/after evidence, human verification and reopening. Synthetic SVG fixtures cannot be used as genuine model evidence; image comparison needs real JPEG photographs. When genuine before/after images are present, run supporting similarity and explain that an embedding cannot establish repair safety. Show Hotspots' source-separated empty state and Operations Search's actual database filters. In Insights, change labelled cost assumptions in the budget simulator.

**2:15–3:00 · Auditable AI and data**
Open `/dashboard/ai-lab`; run a licensed Commons sample. Show the actual model revision/device, raw scores, observed duration and correction count. Explain the measured 4/4 smoke result covers only four convenience images in two classes; it is not general accuracy. Open Data Sources: demonstrate licence, original ID, coverage, dates and explicit MODEL EVALUATION labels. Close with the real implementation boundaries: no paid key, no live council feed, human decisions, separate inference hosting required for public deployment.
